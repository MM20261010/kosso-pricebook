# こっそり価格帳 (Kosso Pricebook) · Android試作 v0.7 品目単価の確認

**商品名・印字単価×数量・行金額を中心に確認し、明示的に確認した税込単価をまとめて保存するデバッグ版です。v0.7の実レシート精度・修正回数はAndroid実機での判定が必要です。**

[v0.7の変更・検証結果・実機比較手順](docs/ocr-v07-validation.md)を参照してください。

買い物前にメモを作成し、店内では過去の店別購入価格を確認。帰宅後はレシートを端末内OCRで読み取って、購入明細を一括保存し、次回の買い物に使います。

## プライバシー優先
- アプリは `INTERNET`・位置情報・カメラ権限を要求しません。外部カメラアプリ・システムの画像選択を利用します。
- レシート・認識テキスト・購入明細は運営者のサーバーへ送信しません。履歴はアプリ内SQLiteに保存します。
- Android自動バックアップは無効化し、JSONバックアップ・復元は利用者が明示操作します。クラウド保存先を選ぶとその提供者へ保存されます。
- OCR学習モデル `jpn`・`eng` は**ビルド時**にAPKへ同梱し、スマホ側では通信・ダウンロードしません。

## 実装コード
- 買い物メモ、チェック、数量変更、店別前回税込価格、最終購入日、特売マーク、価格履歴・税抜換算前回比
- システムカメラ・写真選択による端末内OCR、商品候補・数量・税率・値引きの確認、一括保存
- 手入力、SQLite保存・個別履歴削除、JSONバックアップ・復元

## ビルドと検証
JDK 17、Android SDK 35、Gradle 8.11.1、Android Gradle Plugin 8.9.2、NDK 27.2.12479018、CMake 3.22.1、モデル変換用Python 3.12 を使用。

```sh
sh tests/test-price-math.sh
sh tests/test-parser.sh
sh tests/test-ocr-image.sh
sh tests/privacy-sanity.sh
sh scripts/fetch-ocr-models.sh
python3 scripts/prepare-native.py
python3 scripts/prepare-paddle.py
gradle :app:assembleDebug --no-daemon
```

`app/build/outputs/apk/debug/app-debug.apk` が成果物です。
GitHub Actions の `Test APK (manual run)` は**手動実行専用**。実行後はActionsのArtifactsからデバッグAPKを取得できます。

**未検証・要改善**: Android実機のOCR精度・処理時間・メモリ、レシートの複雑な割引・単価・数量表記、重複登録、商品名の揺れと規格差、更新用署名鍵の固定。OCRモデルは固定コミット・SHA-256で取得とキャッシュを検証します。正式配布やF-Droid掲載は保留。

価格履歴は過去の購入価格で、店頭の現在価格ではありません。税抜換算の価格変化だけで「便乗値上げ」とは断定しないでください。

## v0.7 OCRの確認手順

候補は未選択で、数量未認識は空欄のままです。商品名・単価×数量・行金額を見て、対象商品を選択してください。「選択商品の単価をまとめて確認」で、印字が税込か税抜かを本人が指定します。税抜の場合は税率と**1点単位の端数処理**を確認できる商品だけに使い、混在税率は分けて選択します。割引・合計単位の端数処理・割り切れない単価は詳細で手入力してください。C/Vから税率は決めません。

「全商品を選択」は確認・保存を行いません。確認済み商品の一括保存にも最終確認があります。税込単価を確認できれば、税率は不明のまま保存できます。その履歴は税抜換算比較から除外します。原文・管理情報・座標・集計は展開式の詳細にまとめています。

SQLite v1→v2は既存行を残す追加移行です。旧v1 JSONを復元でき、v0.7の書き出しはv2 JSONになります。**v2 JSONは旧版では復元できません。旧版へ戻すための旧JSONも保管してください。** 画像の任意長期保存は未実装です。JSONに画像・OCR全文・管理番号は含めません。

実レシート画像・認識テキスト・購入履歴をIssueやログへ貼らないでください。
